# Objects exported from other packages

These objects are imported from other packages. Follow the links below
to see their documentation.

- generics:

  [`glance`](https://generics.r-lib.org/reference/glance.html),
  [`tidy`](https://generics.r-lib.org/reference/tidy.html)

- loo:

  [`loo`](https://mc-stan.org/loo/reference/loo.html),
  [`waic`](https://mc-stan.org/loo/reference/waic.html)

- nlme:

  [`fixef`](https://rdrr.io/pkg/nlme/man/fixed.effects.html),
  [`ranef`](https://rdrr.io/pkg/nlme/man/random.effects.html)

- posterior:

  [`as_draws`](https://mc-stan.org/posterior/reference/draws.html),
  [`as_draws_array`](https://mc-stan.org/posterior/reference/draws_array.html),
  [`as_draws_df`](https://mc-stan.org/posterior/reference/draws_df.html),
  [`as_draws_matrix`](https://mc-stan.org/posterior/reference/draws_matrix.html)
